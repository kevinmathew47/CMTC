# Christos Mar Thoma Church, Kakkanad — website design demo

A static preview of the new parish website design, for review.

**View it:** turn on GitHub Pages for this repository (Settings → Pages → Deploy from a branch → `main` / root). The site then appears at `https://<your-username>.github.io/<this-repo>/`.

## What's in the demo

- Every public page of the new design: home, About Us, Organizations, News & Events, Resources and Contact.
- The **Parish Assistant** chatbot, using its built-in answers (the live site can also use Claude AI).
- Photo albums show up to 8 photos each, and images are compressed to keep the demo small.

## What only works on the live site

- The admin panel for updating content.
- Sending the contact form (the demo shows a notice instead).
- Large newsletter PDFs and downloads, which are left out of the demo.

This folder is generated by `npm run demo` in the main website project. Don't edit it by hand; rebuild it instead.
